THE DUNGEON REMEMBERS

"You don't control the dungeon. You ARE the dungeon."

An adaptive 3D subterranean defense strategy roguelite inspired by Dungeon Keeper (1997). Enemies carry collective memory and adapt to your defensive tactics in real time.

GitHub Repository Explore Mechanics

Core Innovations

🧠 Collective Invader Memory

Fallen invaders pass memories back to the guild. Survivors remember which corridors were spiked, avoiding lethal zones and charting flanking paths.

Utility Route Scoring Confidence Decay Memory Chamber [M]

🌋 Living Dungeon Shift

Spend 15 Essence to physically raise impassable obsidian barriers across corridors, altering dungeon geometry and forcing real-time invader rerouting.

Real-Time Pathfinding 15 Essence Cost Dynamic Chokepoints

⚔️ The Grand Inquisitor (Boss)

Arriving in Wave 5, the boss synthesizes your entire playstyle. Overuse spikes? He equips Impalement Plating (-75% damage), forcing tactical counterplay.

Habit Counter-Adaptation Siege Breaker Zealot's Wrath (Phase 2)

Rooms & Arsenal

🏰 6 Modular Rooms

Gate Room, Memory Chamber (+5 Essence), Monster Den (+5 Essence), Trap Room, Treasury (+25 Gold bonus), and the Heart Core Sanctuary (+10 Energy).

⛓️ 4 Lethal Traps

Spike Trap (40G puncture), Falling Rock (60G crush & stun), Poison Fog (50G toxic cloud slow), and Illusion Trap (35G memory fabrication).

👹 3 Garrison Defenders

Goblin Warrior (40G melee brawler), Shadow Beast (70G leap predator), and Mimic (60G disguised gold chest with surprise 45-dmg bite).

Built for the RRR Game Jam • Engine: Godot 4.7.2 (Offline-First GDScript)
